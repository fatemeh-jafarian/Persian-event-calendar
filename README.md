# تقویم فارسی

یک تقویم فارسی راست‌چین با نمای روز، هفته، ماه و سال. می‌توانید رویدادها را با تاریخ شمسی، ساعت، توضیحات و رنگ ثبت، ویرایش و حذف کنید.

## اجرا

در ریشهٔ پروژه دستور زیر را اجرا کنید:

```sh
php -S localhost:8000
```

سپس `http://localhost:8000` را در مرورگر باز کنید. به PHP 8 یا جدیدتر و مرورگری با پشتیبانی از `Intl.DateTimeFormat` نیاز است.

برای افزودن رویداد روی «رویداد جدید» بزنید، تاریخ شمسی و جزئیات را وارد کنید و ذخیره را انتخاب کنید. برای ویرایش یا حذف، روی رویداد در تقویم کلیک کنید.

## فایل‌های برنامه

- `index.php`: صفحهٔ تقویم
- `assets/js/calendar.js`: منطق تقویم، تبدیل تاریخ، مناسبت‌ها و مدیریت رویدادها
- `assets/css/calendar-theme.css`: ظاهر واکنش‌گرای برنامه
- `api/events.php` و `data/events.json`: ذخیره و مدیریت رویدادها با JSON

برای بارگذاری IRANSans باید فایل مجاز وب‌فونت `IRANSansXFaNum-DemiBold.woff2` را در `assets/fonts/` قرار دهید.

رویدادها در فایل موقت `data/events.json` ذخیره می‌شوند. در نمای روز یا هفته روی خانهٔ ساعت کلیک کنید تا فرم رویداد با همان تاریخ و ساعت باز شود؛ خانهٔ تمام‌روز هم رویداد بدون ساعت می‌سازد. تعطیلات قمری با تقویم محاسباتی برآورد می‌شوند و ممکن است با تقویم رسمی ایران یک روز اختلاف داشته باشند.
