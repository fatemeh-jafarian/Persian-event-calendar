# تقویم فارسی

یک تقویم فارسی راست‌چین با نمای روز، هفته، ماه و سال. این برنامه بدون پایگاه‌داده اجرا می‌شود و رویدادهای نمونه و مناسبت‌ها را در مرورگر می‌سازد.

## اجرا

در ریشهٔ پروژه دستور زیر را اجرا کنید:

```sh
php -S localhost:8000
```

سپس `http://localhost:8000` را در مرورگر باز کنید. به PHP 8 یا جدیدتر و مرورگری با پشتیبانی از `Intl.DateTimeFormat` نیاز است.

## فایل‌های برنامه

- `index.php`: صفحهٔ تقویم
- `assets/js/calendar.js`: منطق تقویم، تبدیل تاریخ، مناسبت‌ها و رویدادهای نمونه
- `assets/css/calendar-theme.css`: ظاهر واکنش‌گرای برنامه

تعطیلات قمری با تقویم محاسباتی برآورد می‌شوند و ممکن است با تقویم رسمی ایران یک روز اختلاف داشته باشند. رویدادهای نمایش‌داده‌شده صرفاً نمونه‌اند و ذخیره نمی‌شوند.
